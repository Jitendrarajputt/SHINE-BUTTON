# ✨ SHINE-BUTTON

> A modern, animated Shine Button component built using **React + TypeScript + Vite**.

SHINE-BUTTON is a reusable UI component that adds a smooth shine animation effect to buttons, enhancing user interaction and visual appeal in modern web applications.

## 📦 Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Jitendrarajputt/SHINE-BUTTON.git
```

### 2️⃣ Navigate to the project folder

```bash
cd SHINE-BUTTON
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start development server

```bash
npm run dev
```

The application will run on:

```
http://localhost:5173
```

---

## 🧩 Usage Example

Import and use the ShineButton component inside your application:

```tsx
import ShineButton from "./components/ShineButton";

function App() {
  return (
    <div>
      <ShineButton>
        Click Me
      </ShineButton>
    </div>
  );
}

export default App;
```

## 💡 How It Works

The shine effect is created using CSS animations combined with positioning and transition effects.  
React handles component rendering, while TypeScript ensures type safety and maintainable code structure.
